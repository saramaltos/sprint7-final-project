# Sprint7-final-project – Analysis ConnectaTel

Este repositorio contiene el análisis realizado durante el Sprint 7 del caso ConnectaTel como parte del proyecto final.
Abarca 3 datasets: 
-	El dataset `plans` incluye los dos planes de servicio y no presenta valores faltantes ni inconsistencias. 
-	Los datasets `users` y `usage` incluyen 4000 registros de usuarios con valores faltantes, sentinels, outliers y problemas de calidad, diseñados para simular datos reales del retail. 

## 📂 Contenido del repositorio

- `notebooks/sprint7-final-project.ipynb`
  → Notebook principal con limpieza, EDA, distribuciones, detención de outliers y conclusiones.

## ▶ Cómo abrir el notebook 

1. Abre el archivo `.ipynb` en GitHub

## 📘 Cómo reproducir el análisis

1. Abre ` notebooks/sprint7-final-project.ipynb `
2. Ejecuta las celdas en orden
3. El notebook carga automáticamente el dataset desde `/data/` o desde un enlace público (según corresponda)

## 🧠 Objetivo del análisis

- Identificar problemas de calidad de datos
- Construir un pipeline de limpieza reproducible
- Analizar comportamientos, distribuciones y outliers
- Generar insights para el equipo de Estrategia e Integración de ConnectaTel.
